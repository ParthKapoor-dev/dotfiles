# nox desktop: official-repo packages (pacman). Read by install.sh (`./install.sh --only packages`)
# and `nox doctor`.
#
# Format: one entry per line; `#` starts a comment.
#   pkg              install pkg
#   pkg | other      either one satisfies the entry (the first one is installed)
#   pkg | ~/path     an existing path also satisfies it (something installed by hand)
# Only what this desktop uses; derived from the commands the scripts, the Lua config and the
# QML call. Personal apps and build tools are in optional.txt.
